## UI 方針(ユーザーフィードバックで確定)

初回実装はマイク/システムを**縦2行**に積み、各行右に独立ミュートボタンを置いたが、「縦に大きくなり見た目が悪い」「ボタンを増やさず、メータ左の既存アイコン自体をボタン化してほしい」とのフィードバックを受けて改修:

- **横並び1行**に戻す: `[🎤ボタン][マイクメータ][🔊ボタン][システムメータ]`(従来の `.minimeters` グリッド)
- メータ**左の既存アイコン(🎤/🔊)自体をミュートトグル**化(別ボタンを追加しない)
- ミュート時: アイコン→スラッシュ(Mic→MicOff / Volume2→VolumeX)+ ボタン赤 + 該当メータをグレーアウト
