# 要約プロンプト改善 — 選定根拠

> 作成: 2026-06-26
> 対象: `core/summary/summarizer.py`
> ブランチ: `feature/summary-prompt-tune`

## 背景

ソースガイド機能(`feature/source-guide`)で導入したドキュメント要約プロンプトが冗長/弱い。具体的には:

```python
# Before
"以下の文書を 3〜5 文の日本語で要約してください。"
"箇条書きにはせず、平易な日本語で 1 段落にまとめてください。"
```

これは vanilla すぎて、ローカル LLM(Qwen2.5:14b / gpt-oss:20b 等)で **幻覚** や **思考過程の漏出**, **エンティティ抜け** が出やすい。Deep Research で最新の知見を調査し、設計原則を明文化したうえでテンプレートを差し替えた。

## Deep Research で得た知見(2025-2026)

| 知見 | 出典 | 採否 |
|---|---|---|
| **Reasoning Budget Paradox**: CoT/長い推論は要約 faithfulness を必ずしも上げない。短い「忠実圧縮」では vanilla 寄りが強い | arXiv 2512.03503 | **採用** — CoT 風指示を避ける |
| **Chain of Density**: エンティティ網羅は人間評価で好まれるが、最大密度は逆効果 | arXiv 2309.04269 | **採用** — 「過不足なく」+「詰め込みすぎない」 |
| **Format 制約の効果**: 一貫性は確実に改善(faithfulness 単独効果は未立証だが害は少ない) | arXiv 2507.05123 | **採用** — 3〜5 文/句点終止/箇条書き禁止 |
| **gpt-oss `Reasoning: low/medium/high`** | OpenAI HF card | **不採用(今フェーズ)** — モデル名検出は次フェーズ。今回は両モデル共通テンプレで |
| 否定指示単独で faithfulness 改善 | arXiv 2507.05123 系 | **refuted** — 一貫性に寄与する程度の効果として採用 |
| Atomic-fact + NLI による自己批判ループ | arXiv 2512.05387 | **次フェーズ** — プロンプトではなく評価ハーネスに組む |

## 採択したプロンプト構成(案 A + 案 B のハイブリッド)

```
# Intro
あなたは与えられた資料の内容のみを用いて、簡潔かつ忠実に日本語で
要約するアシスタントです。

# 制約
- 資料に書かれていない事実、推測、一般常識による補完は一切行わない。
- 重要なエンティティ(人物・組織・製品・数値・日付・固有概念)を
  見落とさず、過不足なく含める。
- 出力は日本語の平文で、句点で終わる 3〜5 文。
  箇条書き・見出し・前置き・後書きを禁止する。
- 推論過程・思考過程を出力しない。要約本文のみを返す。
- 固有名詞・数値・日付は原文表記を尊重する。
- 情報量と読みやすさを両立させ、詰め込みすぎない。

# 資料
{joined_chunks}
(注: 切り詰めが発生した場合のみ、欠落部分を推測しない旨の注釈を動的挿入)

# 要求
上記資料の要点を 3〜5 文の日本語で要約してください。
```

### キー設計判断

- **persona は最小限**: 「忠実圧縮アシスタント」のみ。CoT を引き出さない。
- **エンティティの列挙指示**: CoD 由来。ただし「内部で列挙→本文生成」の手順は書かない(思考漏出のリスク)。
- **思考過程出力の禁止**: gpt-oss/LRM 系の防御。
- **切り詰め注釈は動的挿入**: 切り詰めが発生したときだけ「先頭から一部のみ抜粋」「欠落部分を推測しない」を追加する。常時注釈は短文資料で逆効果。
- **temperature**: 既存の 0.2 を維持(Qwen は 0 で劣化報告あり、研究上は 0.2〜0.4 が無難)。
- **few-shot**: 採用しない。短文要約タスクでは vanilla が複雑戦略と同等以上(arXiv 2512.03503)。faithfulness が不足する場合のみ次フェーズで検討。

## 今回は対象外(次フェーズ候補)

- gpt-oss 専用 `Reasoning: low/medium/high` 切替(モデル名検出で system に挿入)
- Atomic-fact 分解 + NLI による自己批判ループ(評価ハーネス側)
- 議事録/書き起こし用の専用テンプレ(現状は混在対応の汎用 1 本)
