# ECN-001: 表・図サイドカー抽出とベータ機能フラグ基盤 (Stage 1)

- **ステータス**: 適用済 (PR #24、2026-07-23 マージ)
- **種別**: 機能追加
- **対象コミット**: `ce3ce4f2..eb0f6e2c` (21コミット)
- **規模**: 61ファイル、+3,546 / -24
- **影響ファイル**: `core/features.py`, `core/storage/assets_repo.py`,
  `core/ingestion/` (PDF パーサ), `core/generation/`, `apps/api/routers/features.py`,
  `apps/web/` (設定画面・Source Viewer)

## コンテキスト

PDF を取り込むと、表は罫線が失われてセルの対応が壊れ、図は本文テキストから完全に
脱落していた。RAG の回答が「表に書いてある数値」を答えられない状態が常態化していた。

同時に、この一連の改修は**4段階(Stage 1〜4)にわたる大きさが見込まれ**、途中の
不完全な状態を全ユーザーに露出させたくないという要件があった。

## 対策

### 1. 汎用ベータ機能フラグ基盤 (`core/features.py`)

コード内のフラグレジストリ + `settings.json` へのオプトイン永続化。
ゲートは必ず `is_enabled` / `require_feature` を経由させる規約とした。

- `dcad7fa` レジストリと `is_enabled` 判定
- `d111c5f` `FeatureService` (settings.json 永続化)
- `d912742` `/api/features` と `require_feature` ゲート
- `4ad067f` 設定画面のベータ機能セクション

**採用しなかった案**: 環境変数フラグ (再起動が必要で試用に向かない)、
ブランチ分離 (統合コストが後ろ倒しになる)。

**規約として明文化した点** (ADR-005):

- ベータ期間のデータは**ベータ非依存スキーマ**で作る → GA 昇格時にマイグレーション不要
- OFF 時もデータは保持し、**露出だけを消す** → ON/OFF の往復でデータが壊れない

### 2. 表の二重表現 (ADR-007)

取込時に表領域の本文テキストを除外して **Markdown 表**を本文に挿入し、
**完全な HTML** を `chunk_assets` に保存する。

生成時は**結合セルを含む表のみ** `md_snippet` → HTML に置換する (`471eef9`)。
単純な表まで HTML にするとトークンを浪費するため。

### 3. 図はクロップ画像のサイドカー (ADR-006)

`chunk_assets` (id/source_id/chunk_id/kind/page/bbox/html/md_snippet/image_path)
+ `data/assets/<source_id>/` にファイル保存。**ベクトルには乗せない**。
再取込・ソース削除時は行とディレクトリを一括削除して再構築する (冪等)。

## 結果

- 表の罫線と結合セルが保持され、Source Viewer でも実表示されるようになった
- 21コミット中**後半5件がレビュー・実機由来の穴埋め**だった。機能追加そのものより
  「ゲートの掛け漏れ」の方が多かった:
  - `b2afa65` Source Viewer の**全文表示ビュー**で表アセットHTMLが描画されない
  - `e562aab` `GET /sources/{id}/content` がベータON時も表Markdownを埋めない
  - `38532d9` 全文表示ビューの表HTMLに罫線CSSが当たっていない
  - `04c6f8c` GA昇格済みフラグへのオプトイン変更が 500 (400 が正)

## 教訓

- **フラグゲートは「機能を追加した経路」だけでなく「既存の全経路」に掛かっているかを
  数え上げる**。表示経路が2つ (カード表示 / 全文表示) あることを実装時に見落とし、
  レビューで2回同じ種類の指摘を受けた
- ベータ基盤を**機能本体と同じPRで入れた**のは正解だった。第1号の適用先が同時にあると
  「ゲートを通す」規約が具体的な形で確定する
- サイドカー方式 (本文とは別テーブル + ファイル) は、**再取込の冪等性**を
  「行とディレクトリの一括削除」という単純な操作に落とせる点が効いた
