# DOM 観測エビデンス (MutationObserver 捕捉)

Playwright MCP のブラウザが本セッション中に散発的にクラッシュしたため、
一瞬しか表示されない「続きを生成中… (n/max)」ステータス行は、送信前に
`MutationObserver` を仕込んで時刻付きで捕捉した。生成が qwen2.5:0.5b で高速
(round0 が 5〜13 秒で完了)なため、離散スクリーンショットでは表示中の瞬間を
取り逃すが、以下は実 DOM に描画された事実の記録である。

## AC3 手動継続中の旧警告注記チェック (レビュー修正点)

手動継続ストリーミング中、メッセージ本文に「打ち切られました」注記が
後続テキストと共に本文途中へ挟まらないことを MutationObserver で監視:

- 監視ティック数: 136 (ストリーミング全域)
- 本文途中に注記+後続本文を検出した回数 (t>1ms): 0 件
- 唯一の検出 (t=1ms, 後続114字) はフェードアウト中のクラッシュレポート
  ダイアログ本文であり、ストリーミングされた継続本文ではない (誤検知)。
  サンプル: " ▶ 続きを生成 履歴: 直近1往復が含まれます 送信 ソースまたは
  引用を選択してください クラッシュレポート機能 NotebookOllamaでエラーが発生…"
- 手動継続中も "続きを生成中… (1/2)" を t=2277ms に捕捉

結論: 継続中に旧警告注記が本文途中へ挟まる現象は観測されず。継続本文
(第7章・第8章)は同一吹き出しへ注記なしで追記された。
